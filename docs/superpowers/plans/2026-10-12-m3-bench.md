# MTxCC M3 成绩期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 基准评测基建——XBOW adapter、本地靶场 e2e、评测回放、成绩报告。插 key 即跑分。

**Architecture:** benchmark 包（adapter 抽象 + XBOW/腾讯黑客松/DVWA 实现）+ 评测 runner + 成绩对比工具。

## Global Constraints
同 M0-M2；adapter 全部实现接口但跑分需 env 提供 key（跳过逻辑）。

---

### Task 1: 基准 adapter 接口 + XBOW adapter
Create: `internal/benchmark/adapter.go` + `internal/benchmark/xbow.go`；Test: unit。
- `Adapter` 接口：`ListChallenges/StartChallenge/SubmitFlag/StopChallenge`
- XBOW：HTTP API 实现（认证 via env MTX_XBOW_TOKEN）
- 腾讯黑客松：MCP/HTTP adapter（API 文档已在 analysis/22）

### Task 2: 本地靶场 adapter（DVWA）
Create: `internal/benchmark/dvwa.go`；Test: docker。
- DVWA 容器启停 + flag 确认（SQLi/RCE/Upload 三类）

### Task 3: 评测 runner
Create: `internal/benchmark/runner.go`；Test: docker。
- 按基准枚举题目→逐题启动 MTxCC 任务→等待→收集 findings→评分
- 成本/时延/token 用量统计

### Task 4: 成绩报告与对比
Create: `internal/benchmark/score.go`；Test: unit。
- 结构化成绩 JSON（发现数/误报率/成本/时延）
- 与 Decepticon(102/104)、RedAmon(101/104) 等对比表

### Task 5: CLI 入口 `mtx bench`
- `mtx bench --adapter xbow|dvwa|tsec --model <profile>` 一键跑分

### Task 6: 验收
- 全套件绿 + DVWA adapter docker 测试 + tag `v0.4.0-m3`
