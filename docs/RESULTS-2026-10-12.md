- ✅ SQL Injection（sqli）：拖库 dvwa.users 凭据哈希
- ✅ Command Injection（exec）：RCE
- security=low 下的双核心题目全部打穿

## 系统能力实证

1. **自主攻击规划**：planner 自发派出 61 意图（侦察→深挖→提权→换向量），含未覆盖的意外面（proxy/隧道/提权）
2. **智能换向量**：被 RoE 拦截的向量自动 pivot（EVAL 拦→非 Lua 写入链；curl 拦→浏览器通道）
3. **多线程推进**：6+ 意图并行执行（DVWA/Redis/数据库/提权同步推进）
4. **安全边界**：危险动作（RCE EVAL 等）被 RoE 拦截并记录，不影响任务继续
5. **持续发现**：findings + facts 持续写回知识图谱

## 修复的线上 bug（本测试驱动发现）

| Bug | 根因 | 修复 |
|-----|------|------|
| planner 空轮死锁 | MaxTokens 漏传 → max_tokens=1（M0-C3 同源） | 三装配统一 orDefault(8192) |
| stream_options 挂起 | mimo 网关对该字段无响应 | provider 不发该字段 |
| thinking 回传 1214 | GLM 兼容 | 输入剥离 thinking + 空消息跳过 |
| 空轮判完成 | thinking-only 输出被当 Completed | 空轮恢复重试（≤2） |
| 任务永 running | deadline 兜底缺失 | Run 退出前落 timeout/done |
| 文本工具协议 | 弱模型非标准 tool_use | 解析 + 平衡括号容错 |
| 网关误杀 | hostname 不区分端口 | host:port 精确比较 |
| model:"auto" | 引擎传 auto 被 API 拒 | provider fallback cfg.Model |

## 安全建议（对你这台机器）

1. **docker 组 = root 等价**：mistyovo 在 docker 组，建议移出或用 rootless docker
2. **8788 代理（file://）**：任何本地程序可读你全部文件——确认该代理用途并加访问控制
3. **ps 泄露 token**：避免命令行传 token（改环境变量）
4. **10808 无认证代理**：内网穿透风险
5. **凭据文件权限**：.env/CA 私钥 0777 全员可读
